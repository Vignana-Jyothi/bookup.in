# Container build exclusions

[Source](../.dockerignore). Excludes real environment files, dependency/output directories, credentials/cache/history, artifacts, guides, tests, SQL and Vercel-only functions from the Docker context. Final image COPY lists are narrow as a second boundary.

Only `frontend/` build source, backend runtime code and root manifests/configuration are needed by these images. Exclusions do not change Git tracking, Render configuration, Vercel packaging or the local files. See [operations](project/college-deployment.md).
