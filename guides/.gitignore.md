# Git Ignore Rules

## Deployment cleanup (25 October 2026)

The entire `artifacts/` directory, all `.impeccable/` local tool state and any `.vercel/` metadata are ignored. The seven manual QA helpers are now local-only too; there are no artifact exceptions. Python bytecode, coverage, Playwright/test-result folders and npm cache directories are also ignored. This changes version-control membership, not runtime file access or artifact generation.

The cleanup removes 110 previously tracked generated/tool/local-reference files (10,204,825 bytes) from the Git index with `git rm --cached`; every local copy is retained and checksum-verified. This includes `PRODUCT.md` and `deply_plan.pdf`, which already matched the project's local-reference ignore rules and have no build/runtime references. Application code, registered tests under backend/tests, package manifests/lockfile, deployment configuration, `.env.example` and the selected tracked deployment guides remain versioned. Existing history is not rewritten: Git can still upload old artifact blobs when transferring historical commits. Docker independently excludes the entire artifacts directory.

Verification checks ignored-path behavior, tracked-file membership, local-copy checksums, source build/isolated tests, Compose configuration and the guide reader. Known engine/network/host verification limits remain in [the implementation evidence](project/college-migration-implementation-20261025.md); ignore cleanup cannot establish live deployment readiness.

College migration verification exports are excluded under `/artifacts/college-migration/`; they are generated clean-source snapshots/logs, not application code. Selected deployment/runbook guides are now explicitly force-added to Git despite the general guides ignore rule. The historical no-tracked-guides observation below no longer describes those selected files.

[Source](../.gitignore). Matches dependency/build output, logs, editor artifacts, actual environment files, private token caches and database backups. `.env.example` is explicitly allowed; it must contain placeholders rather than private values.

The source also intentionally ignores `guides`, `tasks` and `AGENTS.md`. On 19 October 2026, `git ls-files guides AGENTS.md` returned no tracked files: local reference changes are not automatically included in GitHub/Vercel deployments or another checkout. A local agent sharing this workspace can still read them.

This documentation audit records that behavior without changing ignore policy or force-adding files. Before deciding to version reference paperwork, review it for private evidence and environment-import material, choose the intended shareable paths, and explicitly update tracking policy. Removing an ignore rule alone does not commit files. Do not force-add secrets, token caches, database backups or private configuration.
