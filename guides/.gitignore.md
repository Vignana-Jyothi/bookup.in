# Git Ignore Rules

College migration verification exports are excluded under `/artifacts/college-migration/`; they are generated clean-source snapshots/logs, not application code. Selected deployment/runbook guides are now explicitly force-added to Git despite the general guides ignore rule. The historical no-tracked-guides observation below no longer describes those selected files.

[Source](../.gitignore). Matches dependency/build output, logs, editor artifacts, actual environment files, private token caches and database backups. `.env.example` is explicitly allowed; it must contain placeholders rather than private values.

The source also intentionally ignores `guides`, `tasks` and `AGENTS.md`. On 19 October 2026, `git ls-files guides AGENTS.md` returned no tracked files: local reference changes are not automatically included in GitHub/Vercel deployments or another checkout. A local agent sharing this workspace can still read them.

This documentation audit records that behavior without changing ignore policy or force-adding files. Before deciding to version reference paperwork, review it for private evidence and environment-import material, choose the intended shareable paths, and explicitly update tracking policy. Removing an ignore rule alone does not commit files. Do not force-add secrets, token caches, database backups or private configuration.
